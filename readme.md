# 🧮 Calculator Using Python & Streamlit

A simple and beginner-friendly calculator built using **Python** and **Streamlit**.

This project performs basic mathematical operations through a simple web interface.

Link:

## 🚀 Features

* Addition
* Subtraction
* Multiplication
* Division
* Division-by-zero error handling
* Simple and clean Streamlit interface

## 🛠️ Technologies Used

* Python
* Streamlit

## 📁 Project Structure

```text
Calculator/
│
├── app.py
├── requirements.txt
└── README.md
```

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/vedantacharya21/calculator.git
```

### 2. Open the project folder

```bash
cd calculator
```

### 3. Install the required library

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

Run the following command:

```bash
python -m streamlit run app.py
```

The application will open in your browser.

## 🧮 How It Works

1. Enter the first number.
2. Enter the second number.
3. Select an operation.
4. Click **Calculate**.
5. The result will be displayed on the screen.

## 📌 Example

If:

```text
First Number: 20
Second Number: 5
Operation: Division
```

The output will be:

```text
Result: 4.0
```

## ⚠️ Error Handling

The calculator prevents division by zero.

For example:

```text
10 ÷ 0
```

will display:

```text
Cannot divide by zero.
```
